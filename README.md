# متجر EGO — هوديز وتيشيرتات أوفرسايز

متجر إلكتروني متكامل: واجهة عامة للزبائن + لوحة تحكم للأدمين (منتجات، جرد، طلبات واتساب، فواتير، تقارير) + مزامنة حية إلى Google Sheets.

## التشغيل محليًا
```bash
npm install
npm run dev
```
- الموقع العام: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/admin` (كلمة المرور الافتراضية من `.env`)

## الأوامر
| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل التطوير |
| `npm run build` | فحص البناء |
| `npm test` | اختبارات المنطق التجاري |
| `npx prisma db push` | مزامنة قاعدة البيانات بعد تغيير المخطط |

## الإعدادات الخارجية (تُركت فارغة وبجاهزيتها للربط)
- رقم الواتساب ورقم شام كاش: من لوحة التحكم ← الإعدادات.
- Google Sheets: من لوحة التحكم ← التقارير ← ربط الجدول (دليل مفصل في `docs/DEPLOY.md`).
- الصور: رابط صورة مباشر أو رفع مع تمكين Vercel Blob.

## المستندات
